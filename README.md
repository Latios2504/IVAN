# IVAN

Designing and developing an intelligent system to support and manage volunteer activities

Tạo các nhánh feature từ nhánh develop
Từ nhánh develop, mỗi thành viên sẽ tạo nhánh feature riêng để phát triển tính năng của mình.
Ví dụ:
Nhánh cho front-end: feature/fe-login (fe = front-end).
Nhánh cho back-end: feature/be-login (be = back-end).
